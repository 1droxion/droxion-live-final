# Droxion LIVE V2

LIVE V2 is intentionally isolated from the legacy LIVE implementation while reliability is proven.

## Boundaries

- `pages/live/` owns route-level host/viewer screens only.
- `components/` owns DOM/media presentation only.
- `hooks/` owns React lifecycle and the LIVE state machine.
- `services/liveSessionService.js` owns Supabase LIVE control-plane RPCs only.
- `services/liveTransportService.js` owns LiveKit token/connect/publish/disconnect only.
- `services/liveMediaService.js` owns browser camera/microphone acquisition only.
- `types/liveState.js` is the single source of truth for LIVE phases.

## Rules

1. No build-time source rewriting or Vite monkey patches.
2. No DOM-query navigation handoffs.
3. One session ID is generated by the client and used through the whole start flow.
4. UI phase is driven by the state machine, not independent booleans.
5. Supabase session state and LiveKit transport state remain separate layers.
6. A failed transport start cleans up the server LIVE session.
7. V2 must pass repeated host/viewer start-end tests before replacing legacy LIVE.

## Test routes

- Host: `/live-v2`
- Viewer: `/live-v2/view/:sessionId`
